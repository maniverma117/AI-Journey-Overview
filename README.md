## 🎯 How to Use This Series

1. **Start from 01** — Each topic builds on the previous one
2. **Don't skip** — Even if you think you know ML, the explanations connect forward
3. **Follow the story** — AI is a journey where each step solves the previous step's limitation
4. **Teach others** — The best way to learn is to explain

---

## 🧠 The Core Idea

```
Each breakthrough happened because the previous approach had a limitation.

Rules couldn't learn             → Machine Learning
ML couldn't handle complexity    → Deep Learning  
DL couldn't understand context   → Transformers
Transformers needed scale        → Large Language Models
LLMs needed guidance             → Prompt Engineering
Single prompts weren't enough    → Context Engineering
Context needed structure         → Harness Engineering
LLMs couldn't act                → Tool Calling
Tools needed orchestration       → AI Agents
Agents needed standards          → MCP
LLMs needed private knowledge    → RAG
Everything needed frameworks     → Agentic AI Frameworks
Engineers needed no-code         → GUI Platforms
Production needed infrastructure → AWS Bedrock AgentCore
```

## 📖 Teaching Philosophy

> **AI is not magic. It's math, patterns, and engineering decisions stacked on top of each other.**

Every concept is explained by:
1. What problem existed
2. What solution was invented
3. How it actually works (with numbers, not hand-waving)
4. What new problem it created (leading to the next topic)
