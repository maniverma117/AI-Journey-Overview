# 38. Saturation curve

We expect something like:

```text
Latency
  ▲
  │
  │                  /
  │                /
  │             __/
  │          __/
  │       __/
  │______/________________► load
          ^
          │
       knee point
```

At first:

```text
load ↑
throughput ↑
```

Then:

```text
load ↑
throughput increases slowly
```

Then:

```text
load ↑
queue ↑↑
TTFT ↑↑
```

That is the saturation region.

---

# 39. The most important number

We don't want:

```text
maximum possible throughput
```

We want:

> **Maximum sustainable throughput while meeting the SLO.**

For example:

```text
Load      P95 TTFT

10 RPS     400ms
20 RPS     500ms
30 RPS     650ms
40 RPS     850ms
50 RPS     1.8s
```

SLO:

```text
P95 TTFT < 1s
```

Then:

```text
40 RPS
```

may be our sustainable capacity.

Not:

```text
50 RPS
```

# 42. Little's Law in the lab

Now we can actually observe:

```text
L = λW
```

Suppose:

```text

average latency = 2 sec
```

Then:

```text

  = 20 concurrent requests
```

Compare this to:

```text

+

```

You'll start seeing queueing theory become something observable rather than a formula from a lesson.
